타임라인 비주얼라이저(이하 “앱”)는 이용자의 개인정보를 중요하게 생각하며, 앱의 기능 제공에 필요한 범위에서 최소한의 정보만 처리합니다. 본 개인정보처리방침은 앱이 어떤 정보를 처리하며 어떻게 보호하는지 안내합니다.

핵심 안내
앱에서 불러온 타임라인·위치 기록은 이동 경로와 방문 기록을 시각화하기 위한 목적으로 사용됩니다. 해당 데이터는 기본적으로 이용자의 기기 내에서 처리되며, 개발자가 운영하는 별도 서버에 저장하는 것을 목적으로 수집하지 않습니다.

1. 처리할 수 있는 정보

항목 처리 목적 처리 방식
사용자가 직접 불러온 타임라인 및 위치 기록 이동 경로, 방문 지점, 시간대 및 이동 흐름 시각화 앱 기능 제공을 위해 기기 내에서 처리
위치 관련 정보 지도 표시, 위치 기반 시각화 등 사용자가 실행한 기능 제공 기기 권한 및 운영체제가 허용한 범위에서 처리
사용자가 선택한 파일 및 그 안의 메타데이터 타임라인 데이터 불러오기 및 분석 사용자가 직접 선택한 경우에만 접근

앱은 이용자가 선택하지 않은 파일을 임의로 열람하거나, 타임라인 데이터를 광고·마케팅 목적으로 판매하지 않습니다.

사용자가 앱에 불러온 타임라인·위치 데이터는 기본적으로 이용자 기기 내에서 처리됩니다. 이용자는 앱 내부의 삭제 기능, 앱 데이터 삭제 또는 앱 제거 등을 통해 기기에 저장된 데이터를 삭제할 수 있습니다.

개발자가 별도 서버에 이용자의 타임라인 원본 데이터를 지속적으로 저장하지 않는 경우, 개발자는 해당 원본 데이터에 대한 별도의 보유·파기 절차를 수행하지 않습니다.
